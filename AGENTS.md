# QuantSage

QuantSage is a planned Python framework for discovering and falsifying empirical patterns in 30GB+ of irregular financial time-series data, initially focused on government bond futures L2 snapshots. Its workflow moves from data understanding and statistical baselines through events, regimes, and hypotheses to validation and reproducible research knowledge. This repository currently contains specifications and implementation guides rather than application code.
